❓ Como funciona & solução do bloqueio (CORS)

Este tool usa a API do cobalt (o motor do cobalt.tools) — um projeto open-source que baixa mídia direto do serviço de origem, sem anúncios nem rastreio.

✅ Sua instância própria está rodando em http://localhost:9000 (Docker, imagem oficial) — é a primeira opção do modo Auto e funciona 100% local, sem CORS nem anti-bot. Para iniciá-la no boot / reiniciar:

cd ~/cobalt && docker compose up -d   # inicia (restart automático: unless-stopped)
docker compose down                  # para
docker compose logs -f               # acompanhar

Por que às vezes falha direto do navegador? A instância oficial api.cobalt.tools tem proteção anti-bot (Turnstile) e não libera CORS para páginas de terceiros. As instâncias comunitárias geralmente liberam, mas podem cair. Por isso o modo Auto testa a local primeiro e depois as demais.

Alternativa — proxy local (faz a ponte para qualquer upstream, incluindo instância com chave de API):

cd ~/OpenManus
python3 cobalt_proxy.py
# → Proxy em http://localhost:8099  (use a instância "Proxy local")

Para apontar o proxy a uma instância específica:

COBALT_API=https://cobalt-api.kwiatekmiki.com python3 cobalt_proxy.py
  • Auto: tenta as instâncias conhecidas em sequência até uma responder.
  • Customizada: adicione sua própria instância (há listas em instances.cobalt.best e cobalt.directory).
  • Se uma instância pedir chave de API, use uma instância aberta ou a sua própria (self-host).
